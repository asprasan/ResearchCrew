# Features

Below are the main features of ResearchCrew that ensure reliability and citation integrity throughout the research process.

- [Human-in-the-Loop Research](human-in-loop.md) — Actively steer research direction after each round with feedback
- [Citation Integrity](citations.md) — Every claim is traceable to a source URL
- [Reliability Filters](reliability.md) — Web crawler and pipeline checks ensure quality at each stage
