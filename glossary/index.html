    Glossary

    Key terms and concepts in ResearchCrew.

    A

    Agent A specialized AI component in the crew that handles one aspect of research. ResearchCrew has 5 agents: Research Planner, Web Crawler, Content Extractor, Synthesis Researcher, Reporting Analyst. Each agent has a specific role, goal, and tools.

    Attribution The process of linking claims back to their source. In ResearchCrew, every claim in the final report includes a direct citation claim linking to the source. See also: Citation.

    C

    Citation A reference to a source that supports a claim. In ResearchCrew, citations are inline markdown links: [claim text](URL). Clicking the link takes you to the original source.

    Example: AI adoption is increasing

    Confidence Level A measure of reliability assigned to each extracted claim. ResearchCrew uses three levels:

    • HIGH: Peer-reviewed research, official reports, government data
    • MEDIUM: Industry publications, reputable news outlets, expert interviews
    • LOW: Emerging reports, single sources, preliminary findings

    Crew The orchestrator of all agents and tasks. The Crew is responsible for:

    • Managing agent interactions
    • Executing tasks sequentially
    • Storing and retrieving memory
    • Generating final output

    D

    Deduplication The process of avoiding duplicate work. ResearchCrew's memory system deduplicates:

    • URLs already crawled (won't re-crawl same source)
    • Topics already researched (won't repeat research)

    This ensures iterative research builds on prior work rather than restarting.

    Domain Filtering Quality filters applied by the Web Crawler to exclude unreliable sources. Excluded domains include Medium, Reddit, Twitter, etc. This improves research quality by removing low-signal sources early.

    E

    Extraction The process of identifying and pulling out specific claims from a source page. The Content Extractor extracts:

    • Specific claims and assertions
    • Verbatim quotes supporting each claim
    • Confidence levels
    • Source context

    See also: Content Extractor, Verbatim Quote.

    F

    Feedback User guidance provided after reviewing research output. Feedback tells the crew:

    • Topics to explore deeper
    • Topics to de-prioritize or skip
    • Gaps to fill
    • Inaccuracies to verify

    Example: "Please explore mental health impacts more deeply. Skip historical background."

    Feedback Loop The iterative cycle of research → review → feedback → research. Each loop adds refinement based on user guidance.

    G

    Hallucination When an AI model generates false information that sounds plausible but isn't supported by sources. ResearchCrew prevents hallucinations through:

    • Source filtering (domain exclusions)
    • Verbatim quote extraction
    • Confidence scoring
    • Cross-source validation

    H

    Human-in-the-Loop The core design principle of ResearchCrew: humans actively guide research direction after each iteration. Unlike one-shot tools, ResearchCrew is collaborative:

    1. AI conducts initial research
    2. Human reviews and identifies gaps
    3. Human provides feedback
    4. AI iterates with guidance

    This enables research quality that neither AI nor humans alone could achieve.

    I

    Iteration A complete cycle of the research pipeline (planner → crawler → extractor → synthesis → reporting) with user feedback incorporated from prior iterations.

    Each iteration typically takes 5-15 minutes.

    K

    Knowledge Base The system's memory of prior research. ResearchCrew uses LanceDB to store:

    • Prior research outputs
    • Extracted claims and sources
    • Crawler history
    • Deduplication data

    This enables the crew to remember context across multiple iterations and sessions.

    L

    LLM (Large Language Model) The AI model powering all agents. ResearchCrew is configurable to use any LLM supported by OpenRouter:

    • OpenAI: GPT-3.5, GPT-4, GPT-4o
    • Anthropic: Claude 3 Opus, Claude 3 Sonnet
    • Others: Mistral, etc.

    Trade-off: Better models produce higher quality but cost more and run slower.

    M

    Memory The system's ability to retain information across research runs. ResearchCrew uses two types:

    • Long-term memory: Stores research outputs and sources via LanceDB
    • Conversation memory: Maintains context within a single run

    Memory is enabled by default. See also: Knowledge Base.

    O

    Output The files generated by a ResearchCrew run:

    • report.md — Final, publication-ready research report with citations
    • [timestamp]_extraction.json — Raw extracted claims (intermediate)
    • [timestamp]_synthesis.md — Synthesized findings before final reporting (intermediate)

    P

    Pipeline The sequential flow of 5 agents and 5 tasks that constitute research:

    1. Research Planner — Plan what to research
    2. Web Crawler — Find authoritative sources
    3. Content Extractor — Extract verified claims
    4. Synthesis Researcher — Synthesize across sources
    5. Reporting Analyst — Generate final report

    Each stage adds value and includes quality checks.

    Publication-Ready Output suitable for sharing with others without major edits. ResearchCrew reports are publication-ready because:

    • All claims are cited
    • Sources are verifiable
    • Writing is professional
    • Structure is clear

    Q

    Quality Filter Exclusions applied to improve research quality. ResearchCrew applies quality filters to:

    • Exclude unreliable domains (Medium, Reddit, etc.)
    • Exclude sources by confidence level (if user specifies)
    • Exclude unverified sources (verbatim quote requirement)

    R

    Reliability Degree to which research output can be trusted. ResearchCrew prioritizes reliability through:

    • Source filtering (authority validation)
    • Verbatim extraction (no paraphrasing distortion)
    • Confidence scoring (transparency about reliability)
    • Cross-source validation (multi-source confirmation)
    • Explicit gap flagging ("Insufficient data" labels)

    Report The final research output. See Output.

    S

    Search Query The terms used by the Web Crawler to find sources. The Research Planner generates 2-3 search queries based on the research topic.

    Example query: "AI diagnostic tools healthcare accuracy studies 2024"

    Synthesis The process of combining information from multiple sources into coherent findings. The Synthesis Researcher:

    • Groups claims by theme
    • Identifies patterns and trends
    • Flags contradictions
    • Preserves source attribution

    See also: Synthesis Researcher.

    T

    Task An assignment given to an agent. ResearchCrew has 5 tasks:

    1. research_planner_task
    2. web_crawler_task
    3. content_extractor_task
    4. synthesis_researcher_task
    5. reporting_analyst_task

    Each task includes a description, expected output, and assigned agent.

    Traceability Ability to trace claims back to their sources. ResearchCrew ensures traceability through:

    • Direct citations claim
    • Verbatim quotes stored alongside claims
    • Source attribution at every pipeline stage

    U

    User Feedback Direction provided by the user to guide research. Added to the end of report.md and incorporated in the next iteration.

    Example structure:

    ## User Feedback

### Please Explore More:
- Topic X needs deeper analysis
- Add case studies

### Skip Further Research:
- Historical background (already covered)

    V

    Verbatim Quote An exact quote from a source, not paraphrased. ResearchCrew extracts verbatim quotes alongside claims to:

    • Prevent distortion through paraphrasing
    • Allow readers to verify context
    • Reduce hallucination risk

    Example:

    Claim: "AI diagnostic accuracy has improved significantly"
Quote: "Our AI system improved diagnostic accuracy by 30% compared to baseline"
Source: https://example.com/study

    W

    Web Crawler The agent responsible for finding authoritative sources. The Web Crawler:

    • Takes search queries from the Research Planner
    • Uses EXASearch for semantic search
    • Applies domain filtering
    • Deduplicates against prior searches
    • Returns ranked URLs

    See also: Domain Filtering.

    Acronyms

    AI Artificial Intelligence

    API Application Programming Interface. ResearchCrew uses APIs for:

    • LLM access (OpenRouter)
    • Web search (EXASearch)
    • Embeddings (Google Gemini)

    CrewAI The framework powering ResearchCrew. CrewAI provides:

    • Agent orchestration
    • Task management
    • Memory management
    • Tool integration

    EXASearch Semantic web search tool used by the Web Crawler. Provides authoritative source discovery.

    JSON JavaScript Object Notation. ResearchCrew uses JSON for extracted claims output ([timestamp]_extraction.json).

    LanceDB Vector database used for ResearchCrew's long-term memory. Stores research outputs and enables deduplication.

    LLM Large Language Model. The AI engine powering all agents.

    URL Uniform Resource Locator. Web address used in citations.
